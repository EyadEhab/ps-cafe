Project Overview

A complete management ecosystem for PlayStation gaming cafes

🎮

Session Management

Start, monitor, and end gaming sessions with real-time cost tracking and 15-minute billing intervals.

📦

Product Orders

Add snacks, drinks, and extras to any session. Track inventory and per-session product revenue.

💰

Dynamic Pricing

Per-station pricing with day/night rates, weekday/weekend multipliers, and single/multi-player modes.

📊

Reports & Analytics

Dashboard with revenue charts, session history, and top-selling product insights at a glance.

🔐

Role-Based Access

Admin and Worker roles with permission-gated UI: workers manage sessions, admins control everything.

📋

Audit Trail

Every action logged with before/after JSON diffs. Full transparency for all modifications.

08

Security & Permissions

Defense in depth

🔑

JWT Authentication

Token-based auth with configurable expiry and secure HTTP-only transmission.

🛡️

Helmet Security

CSP headers, XSS protection, and other HTTP security headers via Helmet middleware.

⏱️

Rate Limiting

API rate limits (10k/15min) and strict auth endpoint limits (50/15min) via express-rate-limit.

🔒

Input Validation

All endpoints validated with express-validator. SQL injection prevented by parameterized queries.

👤

Role Guards

Admin-only endpoints protected by middleware. Workers see only their permitted views.

🔐

Password Hashing

All passwords hashed with bcryptjs (salt rounds = 10). No plaintext storage.
